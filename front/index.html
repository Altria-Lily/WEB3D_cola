About CakeCola 3D Display

Innovative interactive experience, breaking the boundaries of traditional beverage display

Project Overview

This project is a Web 3D display application for the CakeCola brand, aimed at showcasing our three designed products through interactive 3D models. Users can view products from multiple angles, adjust lighting and materials, and experience the visual characteristics of the products. Additionally, users can send purchase requests to us through the contact form.

Technical Implementation

The frontend of this project uses a modern Web technology stack, including HTML5, CSS3, and JavaScript. 3D model rendering uses the Three.js library, combined with GSAP to achieve smooth animation effects.

HTML5 & CSS3
Three.js
